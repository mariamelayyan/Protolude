# Protolude
construction d'un niveau de jeu vidéo
- Lieu : Ville

- Objet physique : Avion

- Prérequis : Collecter l'eau des 5 fontaines du parc pour éteindre le bâtiment en feu

- Victoire : Le bâtiment en feu est éteint

- Échec : La scène est rechargée lorsque le joueur entre dans le bâtiment en feu sans avoir récupéré toute l'eau des fontaines
